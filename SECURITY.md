# Security policy

## Reporting a problem

If you find a security problem in any Rafline repository, please report it privately. Do not open a public issue, pull request or discussion about it.

To report, send a direct message to Rafline on Instagram (@rafline.eg).

A security@ address will replace this once the domain is live.

Please include:

- what you found and where (repository, file or URL)
- the steps to reproduce it
- what an attacker could do with it

We will confirm that we received your report and keep you updated until it is resolved. Please give us a reasonable amount of time to fix the problem before you share it with anyone else.
